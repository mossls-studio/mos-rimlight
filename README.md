# mos_打光 / mos_rimlight v1.0.0

EffectCraft 传统 2D 偏移边缘打光外部效果辅助程序（`mos.rimlight`，分类 `MOS 视效` / `MOS VFX`，支持 `padding` 画布自动外扩与 EffectCraft 二级菜单折叠分组）。

把传统 AE / EffectCraft 2D 打光需要「复制多层 + 预合成 + 拼贴(Motion Tile) + 偏移/缩放 Alpha 反转遮罩 + 原图曝光压暗 + 中层渐变叠加 + 边缘曝光提亮 + 发光」的一整套繁琐流程，整合进**单个效果插件**里实时调节。

## 渲染层级（自下而上）

1. **底层 · 原图层曝光**：线性光曝光（EV / 偏移 / 伽马），一键压暗人物/主体营造背光氛围。
2. **中层 · 渐变叠加（位于发光层之下）**：可选开启**黑白渐变**（线性 / 径向、起终点可拖、支持反转）或**四色渐变**（4 个画面控制点 + 4 色 + 融合平滑度），支持叠加 / 柔光 / 正片叠底 / 滤色 / 正常混合。
3. **顶层 · 偏移缩放遮罩边缘光 + 高速独立发光**：
   - 使用支持 **镜像边缘 (Mirror) / 边缘延展 (Clamp) / 平铺重复 (Repeat) / 关闭拼贴** 的偏移与缩放遮罩（`Alpha Inverted Matte`），即使人物头顶或脚底贴紧画布边界也**绝不产生穿帮亮边**；
   - 支持**遮罩缩放 %**（`20–300%`，默认 `100%`），配合位置偏移可轻松做出环绕逆光或透视辐射感边缘光；
   - 独立**发光开关**，采用 ROI 局部裁剪 + 多线程降采样双层高斯光晕与紧凑 `padding`（1.5× 半径），流畅不卡顿。

## 效果控件层级排版（适配 EffectCraft 二级菜单）

- **顶层主控**（默认直接展开）：`光照角度`、`边缘厚度 px`、`边缘曝光 (EV)`、`原图层曝光 (EV)`
- **遮罩与拼贴**：`拼贴模式`（镜像边缘 / 边缘延展 / 平铺重复 / 关闭拼贴）、`偏移方式`（角度 + 距离 / 手动 X·Y 偏移）、`遮罩缩放 %`、`遮罩羽化 px`、`遮罩收缩 %`
  - **手动偏移**：`遮罩 X 偏移 px`、`遮罩 Y 偏移 px`
- **原图层曝光**：`原图层偏移`、`原图层伽马`
- **边缘光色彩**：`边缘伽马`、`边缘染色 %`、`边缘颜色`、`边缘不透明度 %`
- **中层渐变叠加**（严格位于发光层之下）：`启用渐变叠加`、`渐变类型`（黑白渐变 / 四色渐变）、`混合模式`、`不透明度 %`
  - **黑白渐变**：`起点位置 (亮)`、`终点位置 (暗)`、`渐变形状`（线性 / 径向）、`反转黑白`
  - **四色渐变**：`点 1–4 位置`、`颜色 1–4`、`融合平滑度 %`
- **发光**：`发光开关`
  - **发光参数**：`发光阈值 %`、`发光半径 px`、`发光强度 %`、`溢出到透明区`
  - **发光颜色**：`光晕染色 %`、`发光颜色`
- **输出**：`输出模式`（合成结果 / 仅边缘光与发光 / 预览偏移遮罩）、`总体混合 %`

## 构建、安装与自测

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
python .\tools\test_helper.py
```

构建产物将自动安装到 `%APPDATA%\EffectCraft\helpers\effectcraft-helper-mos-rimlight.exe`。在已打开的 EffectCraft 窗口中执行 **效果 ▸ 扫描效果辅助程序...**（或重启 EffectCraft），即可在 **MOS 视效** 分类下找到 **mos_打光**。
